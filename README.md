Sobre o projeto

Crud feito para gerenciamento de vendedores e vendas.

Ele foi criado como projeto prático para estudar:

•	ASP.NET Core
•	MVC
•	Front-end com Bootstrap
•	LINQ
•	Conexão com banco de dados via Entity framework
•	Chamadas assincronas usando task (Async, Await)
•	Boas práticas de desenvolvimento
________________________________________
Funcionalidades
✅ Inserção, Atualização e deleção de vendedores e vendas
✅ Filtro de busca simples
✅ Filtro de busca agrupada 
✅ Estrutura simples e escalavel
✅ Ideal para aprendizado de ASP.NET
________________________________________
 Tecnologias usadas
•	ASP.NET Core MVC
•	MySQL
•	Bootstrap
•	Entity Framework
